## 🔄 Image change করার নিয়ম

```bash
# 1. নতুন image টা নিচের নামে save করুন (same name!)
cp ~/Downloads/my-photo.jpg public/images/hero-1.jpg

# 2. Browser refresh করুন — done!
```

## ⚠️ সতর্কতা

- **একই রকম image ব্যবহার করুন** — সব image এ কোনো female person নেই (শুধু male doctor/patient বা medical scene)
- **JPG/PNG format** রাখুন
- **Recommended size:**
  - Hero image: 1920px wide (full screen)
  - Section background: 1600px wide
  - Card image: 600px wide
- **Image compress** করে রাখুন (100-500KB এর মধ্যে) — page fast load হবে
